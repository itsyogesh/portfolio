CodePrint takes a file of code and gives you back something you'd actually want to print: proper typography, syntax highlighting across 19+ languages, line numbers, multi-column layouts, and a live paginated preview before PDF export.

It exists because of an old habit worth keeping — desk checking. Reading code on paper, away from the screen, catches things the editor never shows you.
